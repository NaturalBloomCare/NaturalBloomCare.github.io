# Internal source notes — not for the website

This file is for the Bloom care team. It is not a patient page, not medical advice, and not part of the library.

Do not link it from `index.html`, from a library article, from the footer, or from search. The library search index is built only from `library/*.html` and skips any file whose name starts with `SOURCES`. `robots.txt` asks crawlers not to index this file. The repository is public, so anyone who opens the repo can still read it. If these notes need to stay private, keep a copy outside this site.

Each row is a source that used to appear on a public page, and the fact it supported. Numbers and safety cautions on the public pages were kept. Only the wording and the visible citations changed. A clinician should still confirm the facts against the linked pages before relying on them.

Health Link at 811, 911, and 988 stay on the public pages as safety contacts. They are phone numbers, not citations of advice. “Alberta Health Care” stays where the site explains that Bloom is private and does not bill visits to it. The College of Registered Nurses of Alberta stays in the privacy policy (how long records are kept) and in the careers note (where a Nurse Practitioner permit comes from). Those are licence facts, not health-advice citations.
